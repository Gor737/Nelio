# Nelio backend

NestJS 12 (ESM) + PostgreSQL 18 + Prisma 7, a modular monolith. The design is in `docs/architecture.md`, the decisions in `docs/decision.log.md`, the
choices made where those were silent in `docs/proposed-defaults.md`, the plan in `docs/roadmap.md`, and **how to build, deploy, run and hand over the
API in `docs/release.md`**. The API contract is `openapi.json` (regenerated by `npm run openapi:export`; CI fails when it is out of date).

## Develop

```bash
docker compose up -d           # PostgreSQL 18.6 on 5433 and Mailpit (SMTP 1025, inbox http://localhost:8025), from the repository root
cp ../../.env.example ../../.env   # then set JWT_SECRET (openssl rand -base64 48)
npm ci && npm run prisma:generate
npm run db:migrate:deploy
npm run start:dev              # loads ../../.env; Swagger UI at /api/docs
```

## Check

| Command | What it runs |
|---|---|
| `npm run lint` / `npx tsc --noEmit` / `npm run check:architecture` | oxlint, TypeScript, dependency-cruiser layers |
| `npm test` | unit tests |
| `npm run test:e2e` | e2e tests |
| `npm run test:integration` | real PostgreSQL (the test database `nelio_test` is rebuilt from the migrations): HTTP, concurrency, constraints, sockets, conformance |
| `npm run test:concurrency -- 5` | the race-bearing suites, repeated |
| `npm run db:drift` | migrations versus the Prisma schema |
| `npm run openapi:export` | regenerates `openapi.json` |
| `npm run build && npm run smoke:prod` | the compiled application started with a production environment |
| `npm run db:restore-rehearsal` | backup, restore into a scratch database, compare |

## Operate

`npm run seed:admin` creates the first Admin; the nightly jobs and the log events to watch are in `docs/release.md`.
